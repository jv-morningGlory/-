# Claude Code 实战常用指令

---

## 核心概念

### 会话（Session）

会话就是你跟 Claude 的一次完整对话，绑定到当前项目目录。退出后对话记录保存在本地磁盘，**30 天内可随时恢复**。

**有什么帮助**：

- 关掉终端，`claude -c` 恢复上次对话，不用重复解释背景
- 不同项目各有一套独立会话，互不干扰
- `/resume` 在多个会话之间切换

### 上下文（Context）

上下文是 Claude 的**短期记忆**，有容量上限（约 200K tokens）。对话越长，上下文越接近上限，满了就记不住前面的内容。

### Token

文本的计量单位。**1 个中文字 ≈ 1~2 token，1 个英文单词 ≈ 1 token**。你说的每句话、读的每个文件、改的每段代码都在消耗 token。一个大文件可能就占几万个 token。

### 三者的关系

```
会话（磁盘上的完整记录）
 └── 上下文（当前记忆窗口，有上限）
      └── Token（计量单位，消耗越多上下文越满）
```

## Token 命中率（缓存命中）

### 什么是命中

你每次发消息，都要把之前的对话历史一起发给模型。如果这部分历史跟上次一样，就从**缓存**读取，不用重新计算。一样 → **命中**（快、便宜），不一样 → **未命中**（慢、贵）。

这是所有大模型的通用机制（Claude、DeepSeek 等都一样），不是某个模型特有的。

### 压缩对命中率的影响

**压缩 = 本地对话内容变了 → 发给模型的内容变了 → 模型之前的缓存失效 → 命中率归零**

| 操作 | 对缓存的影响 | 费用 |
|------|-------------|------|
| 正常对话（不压缩） | 缓存持续命中 | 便宜 |
| 压缩一次 | 缓存失效一次 | 这次贵，之后恢复 |
| 频繁压缩 | 缓存反复失效 | 持续贵 |

> 不是必要就别手动 `/compact`，让它自动压缩就行。一次对话聚焦一个任务，聊完 `/clear` 开新的更划算。

## 会话管理操作

### 查看与恢复会话

```bash
claude --resume          # CLI 打开会话选择器
claude -c                # 恢复最近一次会话
```

会话内输入 `/resume` 也可以打开选择器，`Space` 预览、`Ctrl+A` 查看所有项目会话。

### 会话命名

```bash
claude -n "auth-refactor"    # 启动时命名
/rename auth-refactor         # 会话中重命名
```

### /clear、/compact、关闭终端的区别

| 操作 | 对上下文 | 对会话 | 对缓存 |
|------|---------|--------|--------|
| `/compact` | 压缩成摘要，继续对话 | 不变 | 失效一次 |
| `/clear` | 清空，重新开始 | 旧的保留，`/resume` 可恢复 | 清空 |
| 关闭终端 | 不变 | 保留在磁盘 | 恢复时可能失效 |

**怎么看上下文快满了**：输入框上方有 token 使用进度条。

**压缩策略**：上下文快满时 Claude **自动压缩**，保留你的意图、关键文件、待办任务，丢弃完整的工具输出和中间过程。也可手动 `/compact` 提前压缩。

## 回溯与总结（/rewind）

### 打开回溯菜单

- 输入 `/rewind`，或**提示输入为空时按两次 Esc**
- 如果输入框有文字，双 Esc 会先清除文字（文字保存到输入历史，按 `Up` 可调回）

### 菜单操作

回溯菜单列出会话中你发送的每一条消息，选择一个时间点后可选择以下操作：

| 操作 | 效果 |
|------|------|
| **恢复代码和对话** | 代码 + 对话都回到该点 |
| **恢复对话** | 对话回溯，代码保持现状 |
| **恢复代码** | 文件改动回溯，对话保持现状 |
| **从此处总结** | 该点之后的对话压缩为摘要，释放 context window |
| **到此处总结** | 该点之前的对话压缩为摘要，后续消息保留 |
| **算了** | 不做任何更改，返回消息列表 |

> 上下文快满但不想 `/compact` 全量压缩时，用「从此处总结」或「到此处总结」可以**局部释放空间**，更精准。

## 常用指令速查

| 命令 | 用途 |
|------|------|
| `/clear` | 清空上下文，重新开始 |
| `/compact` | 手动压缩上下文 |
| `/resume` | 打开会话列表，切换/恢复 |
| `/branch` | 复制当前对话到新会话 |
| `/rename` | 重命名当前会话 |
| `/config` | 打开设置 |
| `/help` | 查看帮助 |

### CLI 启动参数

```bash
claude                   # 启动新会话
claude -c                # 恢复最近的会话
claude -n "名称"          # 带名称启动新会话
claude -p "指令"          # 非交互模式，执行完退出
claude --resume          # 打开会话选择器
```
