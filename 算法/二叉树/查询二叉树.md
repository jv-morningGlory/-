# 二叉搜索树（BST）

## 是什么

二叉搜索树（Binary Search Tree，也叫**查询二叉树**）是一种**带排序规则的二叉树**：

- 每个节点最多两个孩子：`left`、`right`
- 对**任意节点**都满足：

```text
左子树所有值  <  当前节点值  <  右子树所有值
```

小的永远在左，大的永远在右。  
因此中序遍历（左 → 根 → 右）得到的是**有序序列**，查找时可以按大小定向走，不必扫整棵树。

```text
        5
       / \
      3   7
     / \ / \
    2  4 6  8

中序：2 3 4 5 6 7 8
```

和普通二叉树的区别：普通二叉树左右随便挂；BST **必须左小右大**。

---

## 数据结构

```java
public class BinarySearchTree {

    private Node root; // 树根，整棵树的入口

    private class Node {
        int val;     // 节点存的值
        Node left;   // 左孩子（都比 val 小）
        Node right;  // 右孩子（都比 val 大）

        Node(int val) {
            this.val = val;
        }
    }
}
```

结构关系：

```text
BinarySearchTree
       │
       ▼
     root ──────► Node(val)
                 /          \
              left          right
               │              │
               ▼              ▼
            Node(...)      Node(...)
```

- 树 = 一个 `root` 指针 + 若干 `Node`
- 每个 `Node` 只存：值、左引用、右引用
- **不需要** parent 字段也能做增删查

---

## 基本操作

| 操作 | 做法 |
|------|------|
| 查找 | 从 root 出发，小走左、大走右，相等即找到，走到 null 即没有 |
| 插入 | 同查找路径，找到空位挂上新节点（相等通常不插） |
| 删除 | 见下文（难点） |

---

## 难点：删除

### 图示（删 5）

```text
      5                 6                 6
     / \               / \               / \
    3   7     →       3   7     →       3   7
       / \               / \                 \
      6   8             6   8                 8
                   值改成 6            再删旧的 6
```

### 一句话

> 0/1 孩子：返回孩子顶替；2 孩子：后继值替换 + 再删后继。

## 完整代码

```java
package com.example.styudy.test;

import lombok.Data;

import java.util.ArrayList;
import java.util.List;

public class BinarySearchTree {

    private Node root;

    @Data
    class Node {
        private int val;
        private Node left;
        private Node right;

        Node(int val) {
            this.val = val;
        }
    }

    public void insert(int value) {
        if (root == null) {
            root = new Node(value);
            return;
        }
        this.insertRec(root, new Node(value));
    }

    private void insertRec(Node node, Node newNode) {
        int value = newNode.getVal();
        if (value == node.getVal()) {
            return;
        }
        if (value < node.getVal()) {
            if (node.getLeft() == null) {
                node.setLeft(newNode);
            } else {
                insertRec(node.getLeft(), newNode);
            }
        } else {
            if (node.getRight() == null) {
                node.setRight(newNode);
            } else {
                insertRec(node.getRight(), newNode);
            }
        }
    }

    public Node search(int value) {
        return searchRec(root, value);
    }

    private Node searchRec(Node node, int value) {
        if (node == null) {
            return null; // 没找到
        }
        if (value == node.getVal()) {
            return node;
        }
        if (value < node.getVal()) {
            return searchRec(node.getLeft(), value);
        }
        return searchRec(node.getRight(), value);
    }

    public void delete(int value) {
        root = deleteRec(root, value);
    }

    private Node deleteRec(Node node, int value) {
        if (node == null) {
            return null;
        }

        if (value < node.getVal()) {
            node.setLeft(deleteRec(node.getLeft(), value));
            return node;
        }
        if (value > node.getVal()) {
            node.setRight(deleteRec(node.getRight(), value));
            return node;
        }

        // 找到要删的节点
        if (node.getLeft() == null) {
            return node.getRight();
        }
        if (node.getRight() == null) {
            return node.getLeft();
        }

        // 两个孩子：用右子树最小值替换，再删那个最小值
        Node min = findMin(node.getRight());
        node.setVal(min.getVal());
        node.setRight(deleteRec(node.getRight(), min.getVal()));
        return node;
    }

    private Node findMin(Node node) {
        while (node.getLeft() != null) {
            node = node.getLeft();
        }
        return node;
    }

    public void print() {
        List<Node> nodeList = new ArrayList<>();
        putRec(root, nodeList);
        nodeList.sort((a, b) -> a.getVal() - b.getVal());
        for (Node node : nodeList) {
            System.out.print(node.getVal() + " \n");
        }
    }

    private void putRec(Node node, List<Node> nodeList) {
        if (node == null) {
            return;
        }
        nodeList.add(node);
        putRec(node.getLeft(), nodeList);
        putRec(node.getRight(), nodeList);
    }

    public static void main(String[] args) {
        BinarySearchTree bst = new BinarySearchTree();
        bst.insert(5);
        bst.insert(3);
        bst.insert(7);
        bst.insert(2);
        bst.insert(4);
        bst.insert(6);
        bst.insert(8);
        bst.print();

        bst.delete(5);
        bst.print();
    }
}
```
