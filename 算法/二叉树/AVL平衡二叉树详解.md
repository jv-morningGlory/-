# AVL 平衡二叉树

> 约定：**高度 h** = 空树 0、叶子 1；**平衡因子**（**Balance Factor**，bf）= h(左) − h(右)。部分教材用「右 − 左」，做题前先对口径，判型逻辑一样。

---

## 一、什么是 AVL

**AVL** 是一棵会自己扶正的 **BST**（二叉搜索树）。1962 年由 Adelson-Velsky 和 Landis 提出，所以叫 AVL。

BST 只保证左小右大。连续插入有序序列时，会退化成一条链，查找从 O(log n) 变成 O(n)。

```text
插 10, 20, 30（普通 BST）

10                  10
  \                   \
  20        →         20
                        \
                        30     ← 已经是链表
```

AVL 在 BST 之上多一条硬约束：

> **任意节点**的左右子树高度差不超过 1，即 **|bf| ≤ 1**。

一旦某次插入/删除让某个节点 **|bf| = 2**，立刻旋转，把树扳回来。上面那个例子，AVL 会在插 30 时左旋，变成：

```text
    20
   /  \
  10   30     ← 高度回到 2，查找仍是 O(log n)
```

| | BST | AVL |
| --- | --- | --- |
| 左小右大 | 要 | 要（中序仍然有序） |
| 左右高度差 | 不管 | **每个节点 \|bf\| ≤ 1** |
| 插入/删除后 | 挂上就结束 | 沿路检查，不平衡就旋转 |
| 最坏查找 | O(n) | **O(log n)** |

> 看到「AVL」三个字，先确认两件事：它还是 BST（不能转乱中序），再确认每个节点都平衡。生产环境的 `TreeMap` / `TreeSet` 用的是红黑树；手写 AVL 是为了考试时把旋转做对。

## 二、怎么判断 h 和 bf

旋转之前，必须会给每个节点标 **h** 和 **bf**。标错了，后面四种类型全选错。

### 2.1 高度 h：只看孩子，自底向上

| 对象 | h |
| --- | --- |
| 空（null） | **0** |
| 叶子（左右都空） | **1** |
| 其他节点 | **1 + max(h(左), h(右))** |

公式只有这一条，记死：

```text
h(节点) = 1 + max(h(左孩子), h(右孩子))
```

**必须从叶子往根标。** 任何节点的 h 都依赖孩子，从上往下标必错。

现场动作：

1. 先标所有叶子 = 1
2. 孩子都标完的节点，才能标自己
3. 一路标到根

### 2.2 平衡因子 bf：左高减右高

```text
bf(节点) = h(左) − h(右)
```

| bf | 含义 | 动作 |
| --- | --- | --- |
| +1 / 0 / −1 | 平衡 | 不用动 |
| **+2** | 左子树比右子树高 2 | 这棵子树要旋转（最终右旋） |
| **−2** | 右子树比左子树高 2 | 这棵子树要旋转（最终左旋） |
| > 2 或 < −2 | 标错了，或上一层没及时修 | 回到最低失衡点重算 |

> **+ 就是左高，− 就是右高。** 看到 +2 往左看，看到 −2 往右看。

空节点约定 bf = 0，不用单独处理。

### 2.3 整棵树走一遍

给这棵树每个节点标 h 和 bf（括号里是 bf）：

```text
          8
         / \
        4   12
       / \
      2   6
     /
    1
```

从叶子开始：

| 节点 | h(左) | h(右) | h(自己) | bf | 结论 |
| --- | --- | --- | --- | --- | --- |
| 1 | 0 | 0 | 1 | 0 | 叶子，平衡 |
| 6 | 0 | 0 | 1 | 0 | 叶子，平衡 |
| 12 | 0 | 0 | 1 | 0 | 叶子，平衡 |
| 2 | 1 | 0 | 2 | **+1** | 左高 1，仍合法 |
| 4 | 2 | 1 | 3 | **+1** | 仍合法 |
| 8 | 3 | 1 | 4 | **+2** | **失衡**，要修 |

树上看就是：

```text
              8(+2)  ← 最低失衡点，也是整棵树的根
             / \
         4(+1)  12(0)
          / \
      2(+1)  6(0)
        /
      1(0)
```

插入/删除后不要扫整棵树，只重算「被改节点 → 根」这一条路上的 h / bf。路上**第一个 |bf| = 2** 的节点记为 **A**，先修它。

> 口诀：**叶子 1、空 0；h = 1 + 较高的孩子；bf = 左 − 右；谁先爆 2 修谁。**

## 三、LL / LR / RR / RL 怎么转

命名规则：**第一个字母 = A 哪侧重，第二个字母 = 重侧孩子哪侧重。** 同向单旋，拐弯双旋。

| bf(A) | 重侧孩子的 bf | 类型 | 操作 |
| --- | --- | --- | --- |
| +2 左重 | +1（删除时也可能是 0） | **LL** | 对 A **右旋** 1 次 |
| +2 左重 | −1 | **LR** | 先对左孩子**左旋**，再对 A **右旋** |
| −2 右重 | −1（删除时也可能是 0） | **RR** | 对 A **左旋** 1 次 |
| −2 右重 | +1 | **RL** | 先对右孩子**右旋**，再对 A **左旋** |

插入时还可以按路径记：新节点落在 A 的哪条边上。

| 新节点相对 A 的位置 | 类型 |
| --- | --- |
| 左孩子的左边 | LL |
| 左孩子的右边 | LR |
| 右孩子的右边 | RR |
| 右孩子的左边 | RL |

> 孩子 bf = 0 **只出现在删除**：仍按单旋做。新插入时，重侧孩子必是 ±1。

旋转只动 2~3 个指针，**中序顺序不能变**（BST 性质）。怕写反就记：升上来的节点，它「内侧」那棵子树要过继给降下去的节点。

### 3.1 右旋 / 左旋：手先怎么动

**右旋**（LL 的那一下，也是 LR 的第二下）：

```text
      A                     B
     / \                   / \
    B   T4     →         C     A
   / \                       / \
  C   T3                   T3  T4
```

1. B = A.left，B 升为新根
2. **T3（B 的右子树）过继给 A 当左孩子**
3. A 降为 B 的右孩子

**左旋**（RR 的那一下，也是 RL 的第二下）：

```text
    A                         B
   / \                       / \
  T1  B         →          A     C
     / \                  / \
    T2  C               T1  T2
```

1. B = A.right，B 升为新根
2. **T2（B 的左子树）过继给 A 当右孩子**
3. A 降为 B 的左孩子

双旋没有第三种手法：先把拐弯拧成单旋形态，再做一次单旋。

### 3.2 LL：连续往左偏 → 右旋一次

插入 `30, 20, 10`。A = 30，bf = +2；左孩子 20 的 bf = +1 → **同向，LL**。

```text
    30(+2)              20
   /                   /  \
  20(+1)      →      10    30
 /
10
```

把 20 提上去，30 倒向右边。T3 这里是空，不用过继。

### 3.3 RR：连续往右偏 → 左旋一次

插入 `10, 20, 30`。A = 10，bf = −2；右孩子 20 的 bf = −1 → **同向，RR**。和 LL 镜像。

```text
10(-2)                  20
  \                    /  \
  20(-1)      →      10    30
    \
    30
```

把 20 提上去，10 倒向左边。

### 3.4 LR：先往左再往右 → 先左旋，再右旋

插入 `30, 10, 20`。A = 30，bf = +2；但左孩子 10 的 bf = **−1**（拐弯了）→ **LR**。

```text
    30(+2)          30(+2)              20
   /               /                   /  \
  10(-1)   →     20(+1)       →      10    30
    \            /
    20          10
```

1. 先对左孩子 10 **左旋**：20 转到 10 的位置，整棵变成 LL 形态
2. 再对 A=30 **右旋**：20 成为新根

> 不要直接对 30 右旋。直接右旋会把 20 带到错误位置，中序会乱。必须先把「弯」拧直。

### 3.5 RL：先往右再往左 → 先右旋，再左旋

插入 `10, 30, 20`。A = 10，bf = −2；右孩子 30 的 bf = **+1** → **RL**。和 LR 镜像。

```text
10(-2)              10(-2)              20
  \                   \                /  \
  30(+1)     →        20(-1)   →     10    30
  /                     \
 20                     30
```

1. 先对右孩子 30 **右旋**：20 转到 30 的位置，整棵变成 RR 形态
2. 再对 A=10 **左旋**：20 成为新根

### 3.6 现场 4 步（插完/删完立刻做）

1. **只看一条路**：从被改的节点走到根，只重算这条路径上的 h / bf
2. **找最低失衡点 A**：路上第一个 `|bf| = 2` 的节点（先修它，别跳到更高的）
3. **看两个数定类型**：`bf(A)` + `bf(A 的重侧孩子)` → 对照本节开头的表
4. **转完再往上**：插入最多修 1 次就停；删除可能还要继续，因为子树可能再矮 1

> 口诀：**从下往上找，谁先爆 2 修谁；看 A 定方向，看孩子定单双。**

### 3.7 代码：rebalance 就是那张表

节点里存 `height`，避免每次重算整棵子树。插入/删除回溯时对每个节点调用一次 `rebalance`，顺序自动是「先修最低的」。

```java
int h(AvlNode n) {
    return n == null ? 0 : n.height;
}

void refresh(AvlNode n) {
    n.height = 1 + Math.max(h(n.left), h(n.right));
}

int bf(AvlNode n) {
    return n == null ? 0 : h(n.left) - h(n.right);
}

AvlNode rotateRight(AvlNode a) {
    AvlNode b = a.left;
    a.left = b.right;   // T3 过继
    b.right = a;
    refresh(a);         // 先刷新降下去的
    refresh(b);         // 再刷新升上来的
    return b;
}

AvlNode rotateLeft(AvlNode a) {
    AvlNode b = a.right;
    a.right = b.left;   // T2 过继
    b.left = a;
    refresh(a);
    refresh(b);
    return b;
}

AvlNode rebalance(AvlNode a) {
    refresh(a);
    if (bf(a) > 1) {                 // 左重 → 最终右旋
        if (bf(a.left) < 0) {        // LR：先拧直
            a.left = rotateLeft(a.left);
        }
        return rotateRight(a);       // LL，或 LR 的第二步
    }
    if (bf(a) < -1) {                // 右重 → 最终左旋
        if (bf(a.right) > 0) {       // RL：先拧直
            a.right = rotateRight(a.right);
        }
        return rotateLeft(a);        // RR，或 RL 的第二步
    }
    return a;                        // |bf| ≤ 1，不用转
}
```

判断转对了，只看三件事：

1. 中序仍然有序（BST 没丢）
2. 连续插 `10, 20, 30` 后根必须是 20，不是 10
3. 每个节点 `|bf| ≤ 1`
