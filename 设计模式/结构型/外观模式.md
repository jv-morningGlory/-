# 外观模式(Facade Pattern)

## 解决什么问题

一个功能要串起多个组件(查订单 → 查用户 → 查商品 → 生成报表 → 传 OSS),客户端若自己 new 一堆 Service、记调用顺序,就和子系统**强耦合**。

外观把这 N 步封进一个方法,客户端只调一行,内部细节全屏蔽。

---

## Java 代码示例

电脑开机:内部要 CPU 自检 + 内存加载 + 硬盘读取,用户只按一个开机键。

```java
// ========== 子系统:各自独立的组件 ==========

class CPU {
    void freeze() { System.out.println("CPU 冻结"); }
    void jump(long address) { System.out.println("跳转到 " + address); }
    void execute() { System.out.println("CPU 执行"); }
}

class Memory {
    void load(long address, byte[] data) {
        System.out.println("从 " + address + " 加载内存");
    }
}

class HardDrive {
    byte[] read(long lba, int size) {
        System.out.println("读取硬盘");
        return new byte[size];
    }
}

// ========== 外观:对外只暴露 start() ==========

class ComputerFacade {
    private final CPU cpu = new CPU();
    private final Memory memory = new Memory();
    private final HardDrive hardDrive = new HardDrive();

    private static final long BOOT_ADDRESS = 0x00000000L;
    private static final long BOOT_SECTOR = 0L;
    private static final int SECTOR_SIZE = 1024;

    public void start() {
        cpu.freeze();
        byte[] data = hardDrive.read(BOOT_SECTOR, SECTOR_SIZE);
        memory.load(BOOT_ADDRESS, data);
        cpu.jump(BOOT_ADDRESS);
        cpu.execute();
    }
}

// ========== 客户端:一行搞定 ==========

public class Client {
    public static void main(String[] args) {
        new ComputerFacade().start();
    }
}
```

> 客户端完全不需要知道 CPU、内存、硬盘的存在,也不用关心启动顺序。
